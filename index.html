3D Printer (FDM)
Operating Guide

Reference machine: Creality K1C

APPLIES TO ANY FDM PRINTER 10 PHASES · 34 STEPS

Overview

What This Machine Does

This is a filament-based (FDM) 3D printer. It builds parts layer by layer by melting plastic filament and depositing it according to a digital 3D model. Used for prototypes, brackets, enclosures, replacement parts, and functional test pieces.

⚠ Safety First

  • No loose sleeves, hair, or jewelry near the print chamber while the machine is running.
  • The nozzle can reach up to 300°C and the bed up to around 110°C. Never touch either during or immediately after a print.
  • Keep hands out of the chamber while the gantry is moving.
  • If printing ABS or ASA, make sure the room has ventilation, since fumes build up in enclosed spaces.
  • Do not force the enclosure door while a print is active.

Before You Start

Your 3D model design is finalized, no more changes needed
You have a sliced file (.gcode) ready, or the raw model (.STL/.STEP) if slicing on-site
You know the filament type and color you need
The machine is free (check the booking/sign-up sheet if one exists)
The build plate is clean

Step-by-Step Guide

01
Finalize Your Design
  • 1Complete your 3D model in your CAD software of choice (Fusion 360, Onshape, Tinkercad, etc.)
  • 2Check for common issues before exporting: unsupported overhangs, walls thinner than 0.8mm, and non-manifold geometry.
  • 3Export the model as an STL or STEP file.
  • 4Finalize the design before bringing it to the printer. Editing mid-session wastes machine time and slicing effort.
02
Slice the File
  • 5Open the slicer software set up at the station (Creality Print, Cura, or Bambu Studio, depending on the machine).
  • 6Import your STL/STEP file.
  • 7Select the correct printer profile for this machine.
  • 8Set the material type to match your filament (PLA, PETG, ABS, etc.)
  • 9Adjust supports, infill, and layer height for your part.
  • 10Slice the file and save the resulting .gcode.
03
Prepare the Machine
  • 11Power on the printer using the switch at the back or side.
  • 12Check that the nozzle and bed are clean, with no leftover filament blobs or debris.
  • 13Confirm the correct filament is already loaded, or move to Phase 4 to change it.
04
Load or Change Filament
  • 14From the touchscreen, open the filament/extruder menu.
  • 15To remove old filament, select "Unload" and wait for the nozzle to heat and release it.
  • 16Feed the new filament through the tube until it engages the extruder gear.
  • 17Select "Load" and wait until filament extrudes cleanly and consistently from the nozzle.
05
Level the Bed
  • 18Run the auto bed-leveling routine from the touchscreen (most machines run this automatically before each print, but you can trigger it manually if prints are failing to stick).
  • 19Wait for the process to finish before starting your print.
06
Send and Start the Print

Use whichever method is set up at this station:

  • 20WiFi/App: Connect the app to the assigned printer and upload the .gcode file to start.
  • 21USB stick: Insert the drive with the .gcode file, select it on the touchscreen, and press start.
  • 22Direct USB cable: Connect to the linked computer and start the print through its control software.
  • 23Before pressing start, confirm the bed is clear and the enclosure is closed.
07
Monitor the Print
  • 24Watch the first layer closely. Most failures show up here (poor adhesion, shifting, stringing).
  • 25If the print detaches or fails badly, stop it immediately from the touchscreen rather than letting it run to the end.
08
Remove the Finished Print
  • 26Let the bed cool first if instructed, some plates release parts more cleanly once cool.
  • 27Gently flex the removable plate, or use the supplied scraper, to release the part.
  • 28Do not force it. If a part is stuck, ask a lab assistant rather than risk damaging the plate.
09
Post-Processing (If Needed)
  • 29Remove support material carefully with flush cutters or pliers.
  • 30Sand or clean up rough edges if needed.
10
Shutdown and Cleanup
  • 31Clear any leftover filament scraps from the bed.
  • 32Power off the machine if you're the last person using it for the day.
  • 33Return tools (scraper, cutters) to their designated spot.
  • 34Log your print in the usage sheet if one exists.

Reference

Troubleshooting Quick Reference

Stringing between parts

Fix

Lower nozzle temp slightly, or adjust retraction settings in the slicer.

Print won't stick to the bed

Fix

Re-level the bed, clean the plate with isopropyl alcohol.

Nozzle clogged / no filament flow

Fix

Run the machine's built-in unclog routine, or notify a lab assistant.

Layers shifting mid-print

Fix

Check nothing is obstructing the gantry rods, notify a lab assistant if it persists.
